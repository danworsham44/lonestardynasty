# Lone Star Dynasty — Shared Live Pulse

This update uses only Sleeper for fantasy scoring. No sports-data subscription or API key is needed. Netlify usage still counts against the site's hosting allowance.

1. Check your Netlify team's usage and billing. Leave automatic paid top-ups disabled if your plan offers them, and only enable collection if you're comfortable using your included allowance. This package has not been deployed or tested against your Netlify account.
2. Extract this ZIP into the root of the **existing Git repository** connected to Netlify. Keep all other site assets, existing functions, and your existing `netlify.toml`. The two new source functions are under `netlify/functions`; if your Netlify project uses a custom functions directory, put them, including their `lib` subdirectory, there instead. If the existing repo already has a package manifest, merge in the dependency instead of overwriting unrelated scripts or dependencies.
3. In Netlify, add the environment variable `LSD_SHARED_PULSE=1` for **Functions** in the **Production** deploy context. Push/deploy through the connected repository so Netlify builds the functions and installs dependencies. A drag-and-drop upload of static files is not the setup for these source functions.
4. Check the production function logs for `pulse-collect` and open Live Scores. The first successful run establishes a baseline; later runs capture changes. To stop Sleeper collection and shared-feed reads, remove the variable or set it to `0`, and redeploy. To stop scheduled invocations entirely, remove the collector's exported schedule and redeploy.

The collector samples roughly once a minute from 8 a.m. to 2 a.m. Central during NFL regular-season weeks. The shared view shows up to 50 scoring swings and lead changes per fantasy week, even when no visitors had Live Scores open. Short bursts of smaller increases can qualify if observed within 90 seconds. These are changes in Sleeper totals, not a play-by-play timeline. It cannot reconstruct events from before collection was enabled or infer events during a prolonged collection outage. The matchup cards still use their existing refresh cadence and keep their scroll behavior. When the shared feed is unavailable on first load, the prior device-only feed remains available.
